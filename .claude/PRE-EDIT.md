# Pre-Edit Checklist

Read before every Edit/Write. Hook enforces #2.

1. **Plan first.** Present Plan + Execution Steps + Outcome as bullets.
2. **Wait for approval.** `do it` / `approved` / `proceed` / `go ahead`. Without one of these in the last user message, Edit/Write is denied by the harness.
3. **Frontend (CSS/JSX/HTML/JS):** screenshot before → edit → screenshot after. No `!important`. No inline `style={{}}`. Mobile-first.
4. **No new files/sections/sub-systems** without explicit ask. Extend existing.
5. **No delete without double confirmation.**
